# Skins de monstros (PNG)

Adicione aqui seus arquivos: creeper.png, zombie.png, skeleton.png,
spider.png, pig.png, sheep.png.

Use atlas PNG 64×32 ou 64×64. Eles precisam estar dentro do jogo
ao empacotar o .lovr ou o Windows EXE, não apenas junto ao executável
fused. Sem arquivos, o motor desenha uma skin pixel-art original.

Veja docs/SKINS_MOBS.md para o guia completo e as diferenças em
relação aos modelos clássicos de Minecraft.
